Configurar el acceso de administrador

Aquí se crea (o se cambia) el usuario y la contraseña con los que se entra a admin.html para publicar eventos. La contraseña nunca se guarda: solo un verificador derivado de ella. Si además pegas un token de GitHub, queda cifrado con la contraseña y la página podrá publicar los eventos e imágenes directamente en el repositorio (sin descargar ni subir archivos a mano).

1. Usuario y contraseña

Usa una contraseña larga y que no uses en otro lado (una frase funciona bien). Como el sitio es público, la contraseña es lo que protege el token.

2. Token de GitHub (recomendado)

Cómo crear el token (2 minutos)
  1. Entra a github.com/settings/personal-access-tokens/new con la cuenta dueña del repositorio.
  2. Token name: «Página de eventos». Expiration: lo más largo posible (cuando venza, se genera otro y se repite este formulario).
  3. Repository access: Only select repositories → elige emprendimiento-tec-ccm.
  4. Permissions → Repository permissions → Contents: Read and write. Nada más.
  5. Generate token y cópialo aquí. Solo se muestra una vez.

3. Guardar

Con token: se guarda directo en el repositorio como admin.json y en un minuto ya puedes entrar. Sin token: descarga admin.json y súbelo a la raíz del repositorio.

Ver admin.json generado
Seguridad, en corto. El archivo admin.json es público, pero no contiene la contraseña ni el token en claro: el verificador no permite recuperarla y el token está cifrado (PBKDF2 600 000 iteraciones + AES-GCM). Quien no tenga la contraseña no puede publicar. El token solo puede tocar este repositorio. Si sospechas que la contraseña se filtró, repite este formulario con una nueva y revoca el token en GitHub.
